# Aplikasi Manajemen Tugas

Nama : Yorentiana Rafu
NIM : 202359201030

## Deskripsi
Aplikasi berbasis web menggunakan Laravel untuk mencatat tugas yang perlu dilakukan.

## Fitur
- Menambah tugas
- Melihat daftar tugas
- Menyelesaikan tugas
- Mengedit tugas yang belum selesai
- Menghapus tugas yang belum selesai
- Melihat tugas selesai berdasarkan rentang tanggal
- Melihat laporan jumlah tugas berdasarkan tanggal

## Database
SQLite

## Testing
Menggunakan metode Test Driven Development (TDD).
